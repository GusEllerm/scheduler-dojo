# 2026-09-24 Stage 3 — Levels 1–5

## Goal

Turn the engine + language into *content*: a validated level schema and five calibrated levels, each
teaching one pattern, with a pass bar and a gold bar that mean something.

## Level schema (validated in `sim/level.py:validate_level`)

```
{ "id","title","teaches","story","unlocks":[tier,...], "sensors":[field,...],
  "cluster": {sites|nodes}, "generator": {...}, "duration": seconds,
  "default_policy": "fifo",
  "score_weights": {metric: w}, "score_anchors": {metric: {baseline, reference}},
  "bars": {pass_score, gold_score}, "reference_kata": "<path or source>", "sandbox": bool }
```

`validate_level(level) -> None` raises `LevelError` (a `sim.errors.EngineError`, code per problem) on
anything malformed. `run_level` reads `unlocks`/`sensors`/`score_*`/`bars`/`default_policy` from it.

## Calibration (`scripts/calibrate_levels.py`)

For each level: run the baseline (`default_policy`) and the `reference_kata` over N seeds; set
`score_anchors` so baseline→0 and reference→1 per metric; confirm `score(baseline)≈300`,
`score(reference)≈800`, and the reference clears `gold_score` on every calibration seed while the
baseline does not clear `pass_score`. Writes the anchors back into the level file (deterministic seed
set). This is what makes the bars real rather than decorative.

## The five levels

1. **Warm-up** (sandbox, hand placement) — one big job, four nodes; teach drag/place. No kata.
2. **You can't keep up by hand** (unlocks `order`) — a firehose where only an `order` kata helps.
3. **The big job that never starts** (unlocks `reserve`) — starvation; reserve the head, backfill.
4. **Trust, but verify** (sensors `est_runtime`) — users lie about walltime; timeouts + honesty.
5. **Everyone at the table** (unlocks `fairness`) — one hog dominates; share-aware ordering.

## Split

- Schema validator + level JSONs + reference katas: **orchestrator** (coherence with scoring/goldens).
- `scripts/calibrate_levels.py`: a builder, once the schema is frozen.

## Acceptance

- `validate_level` rejects each malformed shape with the right code (tested).
- Every level loads, runs, and is deterministic (golden per level, per policy).
- Reference kata ≥ gold bar on all calibration seeds; FIFO < pass bar.
- Scores are stable across platforms (goldens committed).

## Outcome

Shipped. `validate_level` gates the schema (codes `level_schema`/`level_metric`/`level_bars`); five
levels authored with reference katas; `scripts/calibrate_levels.py` turns them into fixed-seed puzzles
(baseline→300, reference→800 exactly, Pareto-filtered so gold is earned, idempotent); per-level goldens
in `tests/goldens/levels.json`. Two engine additions: `idle` (the do-nothing baseline) and
`fits_later`/`Cluster.can_host` (the capacity ceiling that made the backfill kata genuinely beat FIFO).
Calibration *rejected* the naive reserve-based backfill (it scored worse than FIFO) and the honest fix
was the gap-fill kata. Fairness is honestly near-1 at util < 1 and its real lesson is deferred.
`run_level` now defaults `seed` to the level's fixed seed. 18 new tests in `tests/test_levels.py`;
**177 passing**. Notes: [[Levels]] + updated [[scheduler_dojo-sim-level]]/scheduler/cluster/errors/builtins.
