# 2026-10-01 Phase 2 Art 1 — direction, mockups, tutorial script

## What happened

- **Two mockups** of "City 3, mid-week" built by design sub-agents from one scene contract:
  `web/mockups/warm.html` vs `web/mockups/cool.html` (self-contained HTML, role-token palettes,
  light+dark). Rendered to `docs/screenshots/art1/`.
- **Decision: cool** — composition reads at a glance, nothing clips, both themes pass contrast.
  Warm contributed legend + annotation discipline. ([[Decision Log]], [[Art Direction]])
- **Token system**: `web/tokens/palette.json` (from cool's tokens, bay floors retuned until
  `node scripts/check_contrast.mjs` passed **all pairs in both themes**; retunes: bay floors ~1.6:1
  large-area vs ground, light playhead deepened, timeout pair moved to ground since timed-out
  vehicles are ink-outlined+labelled). Generators `gen_tokens.mjs` → `tokens.css`/`tokens.ts`
  (Canvas reads live CSS vars).
- **Campus note** ([[Campus]]): every §2 mapping table, the calendar decision (a city's horizon =
  exactly one week; endless uses literal 86,400 s days), ring formula (per-user max bounded slowdown
  over queued jobs, capped, overflow ends the run), scene vocabulary as renderer contract.
- **Tutorial as data** ([[Tutorial]]): schema + `levels/tutorials/city{1,2,3}.json` +
  `scripts/check_tutorials.py` (builder-built) + `tests/test_tutorials.py` — 3 files validate,
  256 tests green. Level-1 patch decision: city editions are whitelisted deterministic patches, not
  forked levels.
