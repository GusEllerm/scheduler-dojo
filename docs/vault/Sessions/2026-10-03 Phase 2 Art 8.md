# 2026-10-03 Phase 2 Art 8 — onboarding polish, accessibility audit, help drawer, touch pass

Art 8 of `PROMPT-ART.md` §9: the fresh-save welcome, the help drawer, tooltips, the keyboard
completion (with the table the drawer promises *implemented as that table's constant*), the
automated accessibility audit that closes the [[Accessibility]] known-gaps list where it can, and
the 820 px / 390-px touch pass. Optional sound is **not** in this stage (deferred, listed honestly).
Mapping authority stays in [[Campus]] (its "Reading the campus out loud (Art 8)" section).

## What shipped

- **`web/src/welcome.ts`** — the fresh-save doorway. A save with no prefs, no progress and no
  progression (`main.ts`: `Object.keys(prefs).length === 0 && Object.keys(progress).length === 0 &&
  progression === undefined`, read BEFORE `applyDriftOnBoot`) gets ONE labelled dialog: what the
  campus is in two sentences, then "Start city 1 ▸" (the existing chain path —
  `campusCity`/`campusTutorial`/`startCampusRun` via `setMode("campus")`) or "Take a walk" (the
  live campus). Suppressed for `?city=` boots and card links; returning saves land on `prefs.city`
  as before ([[Progression]], [[Tutorial]] — the card deliberately does NOT teach what the city-1
  script teaches in place).
- **`web/src/help.ts`** — the "?" drawer (header button, every mode): how to read the campus (swatch
  rows off `readTokens` — the same tokens `campus-render.ts` paints), the controls, the four modes,
  the reduced-motion note, and the shortcut TABLE, which is the exported constant `SHORTCUTS` that
  `main.ts`'s `onGlobalKey` implements (a boot `console.assert` ties the sets; the audit presses
  every row). `MODE_NOTES` titles the mode picker from the same copy. Content is constants +
  `tokens.ts` only — zero engine calls.
- **`web/src/booth.ts` `trapDialog`** — now also a module-level dialog STACK + one window Escape
  listener: with focus outside any panel, Escape closes the TOPMOST open dialog; the focused panel's
  own handler cancels the event, so nothing double-closes. Focus restore is unchanged
  ([[Accessibility]] rule 5).
- **`web/src/main.ts`** — the global shortcut handler: `?` (toggles help; any other open card wins
  until Esc closes it), `Space`/`S`/`1`/`2`/`3` on the live campus via `CampusPlay.keyTogglePlay`/
  `keyStep`/`keySpeed` (they click/press  the REAL Pause/Step/speed controls — `keySpeed` sets the
  select's value and dispatches `change`), guarded against `input/textarea/select/contenteditable/
  .cm-editor`, against open overlays, and (Space/S/digits) over focused buttons/links. Also: the
  hashchange router for `#card=` links in an already-open tab (review 7b — clearing the hash closes
  the card view), and `destroyModes` closes the help drawer and any share card.
- **`web/src/share-scene.ts` + `web/src/campus-thumb.ts` + `web/src/bridge.ts`** — the review-7b
  fixes folded into this commit: the card dialog rides `trapDialog` with `aria-labelledby` and
  focus restore, an in-flight mint cannot resurrect a dismissed card, the card VIEW gates
  `ok = replay.ok && expected_hash !== ""` (a hash-stripped card can never show ✓ — verified live),
  its horizon line reads the MERGED level, the thumbnail cache stores the PROMISE per key (two
  opens no longer start a frame twice), a detached tile canvas is skipped, and the stepping handle
  is released with the new `bridge.stepClose` (`step_close`, engine side landed with `0a7ec7e`)
  instead of a full `step_result` drain (the board froze seconds per tile before).
- **Tooltips (DOM, cheap):** the campus canvas carries a `title` updated by the hit-test under the
  cursor and names its owned buildings in its `aria-label` (`refreshBuildings`); chips, the mode
  picker and offer cards carry `title`s; fairness rows already had theirs.
- **Touch/small screen:** the ≤860 block grows the chips/buttons the player is told to press to
  40 px; the LIVE campus shows its hover detail card on TAP (touch has no pointerleave, so it
  hides after 2.5 s). Hand taps keep playing ([[Campus]]).
- **CSS fixes the audit found (real, not suppressions):** `.campus-why` never set `--sd-ink` and
  its trace rows rendered light-on-paper (1.22:1); `.review-panel .dojo-tl-clock/-legend` (the
  phase-one strip's muted chrome on campus paper, 2.29:1); `.share-card-text dt` dark-on-dark
  (2.65:1); the locked Endless chip's `opacity: 0.55` text replaced by `var(--muted)` ink; the
  timeline scrub/slider got its `aria-label` at the mount itself (the review strip mounted one
  with no name — only main.ts's labeller used to name it); the booth dialog takes initial focus
  (it was the one dialog that opened with focus left outside).

## Deviations and honest notes

- **"Take a walk" = the live campus**, not the phase-one watch strip — the calm door into
  *what the campus is*; watch mode is still one button away.
- The audit is a **proxy**, not a screen reader: no VoiceOver/NVDA pass, and the §9 playtest
  evidence (fresh playtester reaching city 3 unaided) is still owed. Hand/kata timelines still
  ignore `prefers-reduced-motion` (their autoplay) — a known gap kept in [[Accessibility]].
- Contrast sweep exemptions, stated: `disabled` controls' UA-dimmed labels (WCAG 1.4.3 inactive
  components). Everything else must clear 4.5:1 (3:1 large) against its composited background.
- The paused-campus check allows ONE event-driven repaint in its clean window (a late
  `progression_view` answer); churn would be ≫ that, and the counter proves itself alive with a
  Step press first because headless rAF does not tick.
- `?city=1`/`?city=N` boots and card links skip the welcome; a returning save lands on its city
  (both asserted in the welcome case).
- Optional sound: skipped, deliberately (it is the one §9 line with no acceptance bite).
