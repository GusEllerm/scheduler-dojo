# 2026-10-02 Phase 2 Art 4 — hand play, the booth, and city 1 teaches itself

[agent decision] **Art 4 = hand placement on the campus + the city-1 runner + rule cards as kata
splits**, delivered as four TS pieces and zero Python: `CampusPlay.create({ mode: "hand" })`
(`web/src/campus-play.ts`), the booth dialog (`web/src/booth.ts`), the tutorial runner
(`web/src/tutorial.ts`), and the campus-stage wiring (live/hand toggle + "Tutorial: city 1" chip +
`?city=1`, `web/src/main.ts`). The engine surface (`hand_start`/`hand_place`/`hand_tick`/
`hand_result`, `tutorial_load`, `offers_list`) already existed; nothing that decides moved to the
browser ([[Concepts/Campus]] §hand play, [[Concepts/Tutorial]] §the runner).

Hand mode runs at `manual` pacing on purpose: sim time advances **only** on `Time ▶` (`hand_tick`)
or a successful `hand_place`, so a callout can never be raced by the clock and reduced motion is
free. `hand_tick` returns a full `_snapshot`, so the scene reuses `step_once` unchanged.
`hand_place` errors are red toasts with the selection left staged ("needs 2 bays, got 1" is one
click from fixed). Booth-staffing during a hand run *records* the kata (no mid-run policy switch
exists to call; inventing one would be inventing engine behavior): the `booth_staffed` predicate
fires, and the next kata run preselects it via `KataPlayOptions.initialKata` — that record→preselect
bridge is the honest version of "the booth takes over".

The runner reads engine facts only and **cannot hang**: unknown predicates warn and pass, every wait
carries a `max(2 x stride, 3600)`-s sim-time stall watchdog, `timeout_secs` auto-continues, and the
"Skip tutorial" button sits above the callout overlay in z-order. `behind` is deliberately generous
(queue ≥ 3, ring ≥ 0.75, a 900-s wait, or 60 % of the horizon) because city 1's patch has no rings
at all — without the horizon term the booth reveal would wait on a `pressure_moved` that can never
fire in that level.

Five real bugs the acceptance drive exposed (all pre-existing, all now fixed where Art 4 touched):

- **The main page never imported `tokens.css`** — only the harness page linked it, so the live
  campus on the main app has been running clock-only fallbacks since Art 3 (`buildSunGradient`
  threw on an empty token and the `catch` degraded silently). `web/src/main.ts` imports it now.
- **The road band painted over the queued vehicles** (`drawRoad` after `drawQueuedVehicles` in the
  paint pass) — the queue was invisible in every screenshot. Order fixed; see [[Concepts/Campus]].
- **`vehicleBox` disagreed with the painter's `roadSlots`** (left-packed vs slot-centered) — tapping
  a *drawn* vehicle missed it. The hit box now mirrors the renderer lane math ([[Concepts/Campus]]).
- **The hand view went stale on resize** (the live loop self-heals per frame; the hand view has no
  frames) — a hand-mode resize now re-projects the scene.
- **`hand_start`'s first arrival batch is invisible to the viewer** (those jobs are in no `unseen`
  list). The job union is seeded from a decide-nothing idle `start` of the same level — arrival data
  is engine data, not a decision — with queued shells as the fallback.
